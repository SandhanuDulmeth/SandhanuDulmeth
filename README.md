# 🚀 Featured Projects

## 🏗️ NexusEnroll — Microservices Student Enrollment Platform

**Java · Spring Boot · Microservices · Docker · MySQL · Maven · JWT · Flyway · JUnit 5 · Mockito**

A microservices-based university enrollment platform designed with independently deployable backend services.

### Architecture

```text
                       ┌─────────────────────┐
                       │      Frontend       │
                       └──────────┬──────────┘
                                  │
                                  ▼
                       ┌─────────────────────┐
                       │     API Gateway     │
                       │     Port: 8080      │
                       └──────────┬──────────┘
                                  │
            ┌─────────────────────┼─────────────────────┐
            │                     │                     │
            ▼                     ▼                     ▼
      Auth Service         Course Service       Student Service
            │                     │                     │
            ▼                     ▼                     ▼
      Enrollment Service   Faculty Service    Academic Record
            │                     │                     │
            └──────────────┬──────┴──────────────┬──────┘
                           ▼                     ▼
                  Notification Service    Reporting Service
                           │
                           ▼
                         MySQL
```

### Key Features

* Authentication and JWT-based authorization
* Role-based access control
* Student registration and staff provisioning
* Course creation and paginated search
* Course enrollment and waitlist management
* Faculty roster and grading workflow
* Academic records and transcript generation
* Notifications and unread notification tracking
* Enrollment and faculty reporting
* API Gateway routing
* Database migrations using Flyway
* Docker-based local environment

### Testing

```text

Maven Unit & Integration Tests

```

The project includes:

`JUnit 5` · `Mockito` · `Spring MockMvc` · `API Integration Testing`
`Docker Compose` · `Maven` · `Flyway` · `JWT` · `MySQL`
